# 🏏 IPL Player Management System

A console-based IPL Player Management System built using **Core Java**, **JDBC**, **MySQL**, and **Object-Oriented Programming (OOP)** concepts.

---

## ✨ Features

* ➕ Add Player
* 📋 View All Players
* 🔍 Search Player
* ✏️ Update Player
* ❌ Delete Player
* 🚪 Exit the application

## 🗄️ Database

This project uses **MySQL** as the database.

JDBC is used to connect the Java application with the MySQL database and perform CRUD operations:

* **Create** — Add player
* **Read** — View and search players
* **Update** — Update player details
* **Delete** — Delete player

---

## ▶️ How to Run

1. Clone or download the repository.
2. Open the project in **Eclipse IDE**.
3. Create the required database and table in **MySQL**.
4. Update the database connection details in the project.
5. Make sure the **MySQL JDBC Driver** is available in the project.
6. Run the main Java class.
7. Follow the console menu to manage IPL players.
